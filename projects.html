Open tooling for AUTOSAR delivery — validation, SIL, and ASPICE.

Five public repositories on github.com/ritika-kulkarni that automate DBC/ARXML checks, crash analysis, SIL regression, MISRA triage, and continuous traceability. Filter by discipline, or hit ⌘K to jump somewhere else.

Automated DBC / ARXML Validator & Code-Gen

GitHub

CI and git-hook pipeline that validates DBC and AUTOSAR ARXML (overlaps, endianness, port/interface refs), matches DOORS exports, and generates RTE-style C stubs and interface maps.

Impact: catches signal packing and SWC interface mismatches before Tresos or compile time.

Python DBC ARXML DOORS CI/CD

Lauterbach Trace32 Crash Dump Analyzer

GitHub

Turns Trace32 post-mortem captures into attributed AUTOSAR BSW incident reports — ELF/DWARF symbolication, weighted root-cause classification (CanTp, NvM, OS, …), and optional Jira / Bitbucket publishing.

Impact: hours of manual PC/LR/SP correlation replaced by automated MD/JSON incident packs.

Trace32 ELF Python AUTOSAR

SIL / Virtual ECU Test Harness

GitHub

Software-in-the-Loop harness with a stub COM / PduR / CanIf + J1939 stack on Linux/WSL. Runs fault-injection scenarios (frame drop, bus-off, TP retransmit) on every PR with GTest, gcov, and HTML reports.

Impact: regression without waiting on HIL benches or target MCUs.

SIL Docker J1939 GTest

MISRA / Static Analysis Triage Dashboard

GitHub

Baseline-aware Polyspace / QAC triage gate: parses SARIF and vendor XML, diffs new violations against accepted debt, fails CI on new MISRA Mandatory or ASIL-C/D findings, and opens owner-mapped Jira tickets.

Impact: noisy static-analysis drops become a clean merge gate with attributed tickets.

MISRA C Polyspace QAC Jira

Continuous Traceability Matrix Generator

GitHub

ASPICE L2/L3 sync across DOORS, Git, RQM, and Codebeamer — PR gates on requirement tags and linked tests, plus nightly audit-ready HTML/PDF matrices for release builds.

Impact: replaces drift-prone spreadsheet traceability with a living ALM graph.

ASPICE DOORS RQM Codebeamer
